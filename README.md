# Cube Lab

Cube Lab is a planned browser-based playground for twisty puzzles. It starts with a playable 3×3 cube and gives GitHub profile visitors a way to explore the puzzles that shaped how I approach software engineering.

The project is in the planning stage. This workspace contains a TypeScript starter, and the next milestone is a playable 3×3 prototype.
